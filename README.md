# Everything Hawaii Travel

Static tours-and-activities site. Hawaii (Oahu-forward) is the hand-curated hub;
"Beyond Hawaii" is a multi-network, API-powered catalog of top-rated tours worldwide.
No backend, no database — one data file → generator → static HTML. Hosts free on Netlify.

## Commands

```bash
node build.js                 # generate the site into public/ from the data files
USE_MOCK=1 node fetch/index.js # build sample Beyond-Hawaii data (no API keys needed)
node fetch/index.js            # build Beyond-Hawaii data from live provider APIs (reads .env)
```

Typical flow: `node fetch/index.js` (refresh Beyond data) → `node build.js` (regenerate pages).
Netlify runs `node build.js` on deploy (see `netlify.toml`).

## Data

- `data/tours.json`        — the curated Hawaii catalog (your Excel goes here). Drives home, island, and tour pages.
- `data/destinations.json` — the Beyond-Hawaii destination list (add `viatorDestId` to enable live Viator data).
- `data/beyond.json`       — generated by `fetch/index.js`; do not edit by hand.

## Providers (Beyond Hawaii)

Adapters live in `fetch/providers/`. Each self-disables if its API key is missing.
Keys live in `.env` (never committed — see `.env.example`).

- `viator.js`       — real Viator Partner API call (needs `VIATOR_API_KEY` + `viatorDestId` per destination)
- `getyourguide.js` — stub, wire up when `GYG_API_KEY` is available
- `klook.js`        — stub, wire up when `KLOOK_API_KEY` is available
- `mock.js`         — sample data for development (`USE_MOCK=1`)

Ranking: tours are scored by `rating × log10(reviews + 10)`, de-duped by name, top 10 kept per destination.
